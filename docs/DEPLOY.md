# دليل التشغيل على Railway — بالضغط فقط

هذا الدليل **لا يحتاج طرفية ولا أوامر ولا تنزيل أي شيء**. كل شيء من المتصفح.

---

## الوضع الحالي — لماذا لا يعمل شيء بعد

| الشيء | الحالة |
|---|---|
| الكود | ✅ مكتوب ومرفوع على GitHub |
| GitHub | 📦 **مخزن وليس استضافة** — لا يشغّل شيئًا |
| خادم يشغّل النظام | ❌ **غير موجود بعد — هذا ما سننشئه الآن** |
| المفاتيح | ❌ لم تُوضع في أي مكان (وهذا صحيح — تضعها أنت) |

**Railway هو الخادم.** يقرأ الكود من GitHub، يبنيه، ويشغّله ٢٤ ساعة.

---

## الخطوة ١ — أنشئ المشروع (٣ دقائق)

1. افتح **railway.app** وسجّل الدخول بحساب GitHub
2. اضغط **New Project**
3. اختر **Deploy from GitHub repo**
4. اختر مستودع **market-data-engine**
5. إن طلب منك تفويض الوصول، وافق

سيبدأ Railway بالبناء تلقائيًا. **سيفشل أول مرة — هذا متوقع** لأن المفاتيح لم تُوضع بعد.

---

## الخطوة ٢ — اختر الفرع الصحيح ⚠️ مهم

الكود موجود على فرع تطوير وليس على الفرع الرئيسي.

**Settings** ← **Source** ← **Branch** ← اختر:

```
claude/project-detailed-report-47xcsf
```

---

## الخطوة ٣ — اختر المنطقة (قريبة من بورصات نيويورك)

**Settings** ← **Region** ← اختر **US East** (أو `us-east4` / Virginia).

هذا يقلّل زمن وصول البيانات — ويهم في عقود اليوم الواحد.

---

## الخطوة ٤ — أضف قرصًا دائمًا 💾 لا تتخطَّ هذه

بدون هذه الخطوة **يفقد النظام ذاكرته وكل صفقاته المفتوحة مع كل تحديث**.

1. في صفحة الخدمة اضغط **+ New** (أو **Add Volume**)
2. اختر **Volume**
3. في **Mount Path** اكتب بالضبط:

```
/app/var
```

---

## الخطوة ٥ — ضع المفاتيح 🔑

**هذا هو المكان الوحيد الذي توضع فيه المفاتيح.** ليس في الكود، وليس على جهازك.

اذهب إلى تبويب **Variables** ← **New Variable**، وأضف واحدًا واحدًا:

| الاسم | القيمة |
|---|---|
| `MASSIVE_API_KEY` | المفتاح من massive.com ← **مفاتيح** |
| `MASSIVE_FEED_MODE` | `real_time` |
| `ANTHROPIC_API_KEY` | المفتاح من console.anthropic.com |
| `ANTHROPIC_MODEL` | معرّف موديل Opus (أرسله لك في المحادثة) |
| `TELEGRAM_BOT_TOKEN` | من @BotFather (الخطوة ٦) |
| `TELEGRAM_CHAT_ID` | رقم محادثتك (الخطوة ٦) |
| `DATA_DIR` | `/app/var/data` |
| `JOURNAL_DIR` | `/app/var/journal` |

> 💡 يمكن لصق الكل دفعة واحدة عبر **Raw Editor** بصيغة `المفتاح=القيمة` سطرًا لكل واحد.

**تحذير:** لا ترسل هذه المفاتيح لأحد، ولا تكتبها في أي ملف داخل المستودع.

---

## الخطوة ٦ — بوت تلقرام (٣ دقائق، من جوالك)

1. افتح تلقرام وابحث عن **@BotFather**
2. أرسل `/newbot` واتبع الخطوات (اسم + معرّف ينتهي بـ `bot`)
3. سيعطيك **التوكن** ← ضعه في `TELEGRAM_BOT_TOKEN`
4. ابحث عن بوتك الجديد **وأرسل له أي رسالة** (خطوة إلزامية — البوت لا يستطيع مراسلتك أولًا)
5. افتح في المتصفح:
   ```
   https://api.telegram.org/bot<ضع_التوكن_هنا>/getUpdates
   ```
6. ابحث عن `"chat":{"id":123456789` ← الرقم هو `TELEGRAM_CHAT_ID`

---

## الخطوة ٧ — شغّل

**Deployments** ← **Redeploy**

خلال دقيقتين ستصلك رسالة على تلقرام:

```
🔍 فحص الإقلاع

✅ الإعدادات
    QQQ + 10 أسهم قيادية | وضع البيانات: real_time
✅ بيانات الأسهم
    QQQ آخر إغلاق 485.31 بتاريخ 2026-08-01
✅ سلسلة الخيارات
    214 عقدًا لتاريخ استحقاق 2026-08-04
✅ البث اللحظي
    المصادقة نجحت
✅ محرك القرار
    المفتاح والموديل يعملان
✅ تلقرام
    connected as @your_bot

✅ كل شيء سليم — المحرك يعمل الآن
```

**هذه الرسالة هي إثباتك الوحيد المطلوب.** لا تحتاج فتح أي طرفية.

---

## الخطوة ٨ — لوحة التحكم (اختياري لكن موصى به)

لوحة ويب تعرض كل الصفقات، قرارات الذكاء (بما فيها PASS)، الفرص الفائتة، الدروس بانتظار موافقتك، وتقارير يومية/أسبوعية — كلها بالعربي.

1. من **Variables** أضف:
   ```
   ADMIN_USERNAME=اسم-تختاره
   ADMIN_PASSWORD=كلمة-مرور-قوية-تختارها
   ```
2. اضغط **Redeploy**.
3. من **Settings** بالخدمة، تحت **Networking**، اضغط **Generate Domain** — راواي بيعطيك رابط عام (`https://...up.railway.app`).
4. افتح الرابط، سجّل دخول بنفس الاسم وكلمة المرور اللي حطيتهم، وخلاص.

⚠️ اختر كلمة مرور قوية — هذا الرابط عام على الإنترنت (محمي بكلمة مرور فقط)، وفيه تفاصيل كل صفقاتك.

---

## إن ظهر ❌ أحمر

المحرك **يرفض العمل** ويخبرك بالسبب بالضبط. أرسل لي صورة الرسالة وأصلحها فورًا.

الأخطاء الشائعة:

| الرسالة | الحل |
|---|---|
| `مفقود: MASSIVE_API_KEY` | متغيّر ناقص في **Variables** |
| `اشتراك الخيارات لا يغطي سلسلة العقود` | الباقة ليست Advanced |
| `رُفضت المصادقة` | المفتاح خاطئ أو منسوخ ناقصًا |
| `تلقرام غير مضبوط` | راجع الخطوة ٦ — هل أرسلت رسالة للبوت أولًا؟ |

---

## بعد التشغيل

- **الإشارات** تصلك على تلقرام تلقائيًا أثناء ساعات السوق (١٦:٣٠–٢٣:٠٠ بتوقيت السعودية)
- **قد تمر أيام بلا إشارة** — هذا سلوك صحيح ومقصود، لا عطل
- التقرير الأسبوعي: أرسل لي رسائل تلقرام أو صورة منها وأحلّلها
