# الانقطاع: الأسباب، ومن يكتشفها

مع وجود مشتركين يدفعون، توقف البوت بلا إشعار غير مقبول. هذه قائمة كل حالة
يمكن أن يتوقف فيها العمل، ومن الذي يكتشفها الآن.

| السبب | ماذا يحدث | من يكتشفه |
|---|---|---|
| قاطع الخسارة اليومي | لا يُفتح أي طرح جديد لبقية الجلسة | 🔔 رسالة فورية عند التفعيل (`_announce_circuit_breaker`) |
| انقطاع بيانات السوق | لا تصل شموع؛ إعادة الاتصال آلية بتباعد متزايد | 🔔 رسالة بعد ٥ دقائق صمت داخل ساعات السوق، ورسالة أخرى عند العودة (`_watch_the_tape`) |
| فشل الذكاء (Anthropic) | القرار يصبح PASS آمنًا | سجل + عدّاد؛ لا يوقف المحرك |
| فشل تلجرام | إعادة محاولة ثم تسجيل الفشل | عدّاد `failures` + رسالة عند فشل نشر بطاقة في القناة |
| البوت ليس مشرفًا في القناة | البطاقة لا تُنشر، ويصل النص فقط | 🔔 فحص القنوات عند كل إقلاع + أمر `فحص` |
| خط عربي ناقص (مربعات فارغة) | البطاقات تخرج مشوّهة | 🔔 `cards.self_test()` في فحص الإقلاع وفي أمر `فحص` |
| تعطّل العملية (crash) | Railway يعيد التشغيل (`restartPolicyType: ALWAYS`) | رسالة "فحص الإقلاع" تصل بعد كل إعادة تشغيل |
| **تجاوز ١٠ محاولات إعادة تشغيل** | **Railway يتوقف نهائيًا** | ❗ لا شيء داخل العملية يستطيع الإبلاغ — تحتاج مراقبًا خارجيًا |
| **العملية حيّة لكنها معلّقة** | لا شموع ولا رسائل | ❗ المراقب الخارجي، أو غياب رسالة "🌅 جلسة … بدأت" |

## المراقب الخارجي

العملية الميتة لا تستطيع الإبلاغ عن موتها. لذلك توجد نقطة `/health` — المسار
الوحيد بلا كلمة مرور، ولا يكشف أي صفقة ولا مفتاحًا ولا بيانات مشترك:

```
GET https://<your-app>.up.railway.app/health
{"ok": true, "started_at": "...", "last_bar_at": "...", "last_bar_age_sec": 74,
 "trades_today": 1, "reconnects": 0}
```

اربطها بأي خدمة مراقبة مجانية (UptimeRobot مثلًا) كل ٥ دقائق، واجعل التنبيه
يصل على تلجرام. هذه هي الطبقة الوحيدة التي تكشف موت العملية نفسها.

ملاحظة: `/health` **لم** تُضبط كـ `healthcheckPath` في `railway.json` عن قصد.
لوحة التحكم لا تعمل إلا عند ضبط `ADMIN_USERNAME` و`ADMIN_PASSWORD`، فلو غابت
لأي سبب لأصبح كل نشر جديد فاشلًا في نظر Railway — أي أن فحص الصحة نفسه يتحول
إلى سبب انقطاع. المراقبة الخارجية تعطي نفس الفائدة بلا هذه المخاطرة.

## علامة الحياة اليومية

غياب الإشارات غامض: سوق هادئ ومحرك ميت يبدوان متطابقين من الجوال. لذلك يرسل
المحرك من نفسه:

- 🌅 عند بداية كل جلسة: "جلسة … بدأت — المحرك متصل"
- 🏁 عند الإغلاق: ملخص الجلسة والمراجعة اليومية

صباح بلا رسالة "🌅" هو الإنذار.
